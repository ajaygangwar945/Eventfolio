## 🌿 The Vision

Eventfolio is a premium, highly-interactive portfolio designed with a dreamy **Studio Ghibli aesthetic**. It blends watercolor textures, whimsical animations, and deep technical storytelling to showcase a journey through hackathons, leadership roles, and spiritual adventures.

---

## 🚀 Live Gateway

**Experience the magic live: [eventfolio.vercel.app](https://eventfolio.vercel.app/)**

---

## ✨ Visual Identity

The project follows a "Cyber-Ghibli" design philosophy:

- **Watercolor Foundations**: Soft, hand-painted backgrounds create a warm, nostalgic atmosphere.
- **Floating Lanterns & Spirits**: Subtle CSS animations that breathe life into every page.
- **Glassmorphism**: UI elements use frosted glass effects with smart backdrop filtering for modern legibility.
- **Parallax Vistas**: Multi-layered backgrounds that react to scroll, creating depth and immersion.

---

## 🛠️ Technical Excellence

- **Fluid Responsiveness**: Custom implementation using CSS `clamp()` and flexible grid systems to ensure a perfect experience from the smallest phone to the largest 4K display.
- **Security Hardened**: Comprehensive implementation of `rel="noopener"` and secure link handling across the entire ecosystem.
- **Performance Optimized**: Vanilla JavaScript and optimized SVG assets for lightning-fast load times.
- **Cross-Browser Ready**: Meticulously prefixed CSS (including `-webkit-backdrop-filter`) for full compatibility with Safari and iOS devices.
